# Linux Server Health Monitoring Script

## Project Overview

This project is a simple Bash script used to monitor the basic health information of a Linux server.

The script collects important system metrics such as CPU usage, memory usage, disk usage, uptime, and running services.

## Technologies Used

- Linux
- Bash Shell Scripting

## Features

- Displays hostname information
- Displays current date and time
- Checks CPU usage
- Checks memory usage
- Checks disk usage
- Displays system uptime
- Lists running services


## How to Run

Give execution permission:
chmod +x server_monitor.sh
./server_monitor.sh
